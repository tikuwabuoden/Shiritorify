# Shiritorify

Spotify の曲で遊ぶしりとりゲームです。

## 概要

前の曲名の読みの最後の文字と，次に選んだ曲名の読みの最初の文字が合う曲を Spotify から探してつなげていきます。

## 最小仕様

- スタート画面，プレイ画面，結果画面を用意する
- Spotify API で曲を検索する
- 選んだ曲に読み仮名を入力する
- 同じ曲の再使用は禁止する
- 制限時間内に答えられなかった場合は失敗にする
- 連続正解数をスコアにする

詳しい仕様は [docs/Spec.md](docs/Spec.md) を参照してください。

## 技術方針

- フロントエンドとAPIは Next.js + TypeScript を想定
- 曲検索には Spotify Web API を使う
- 最初はログインなしで遊べるMVPを目指す
