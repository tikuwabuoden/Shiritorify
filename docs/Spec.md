## 最小仕様

### 画面

* スタート画面
* プレイ画面
* 結果画面

### ゲームルール

* 最初の曲をランダム表示
* ユーザーがSpotifyで曲を検索
* 曲を選ぶ
* 前の曲名の最後の文字と，次の曲名の最初の文字が合えば成功
* 「ん」で終わったら失敗
* 制限時間内に答えられなかったら失敗
* 同じ曲は再使用禁止

### 曲データ

保存する情報はこれ．

```ts
type Track = {
  spotifyId: string
  name: string
  artistName: string
  albumImageUrl: string
  spotifyUrl: string
  previewOrEmbedUrl: string
  reading: string
}
```

### 読み仮名仕様

Spotify APIだけでは曲名の読みが取れないから，最初はこれが現実的．

* 曲を選んだあと，読み仮名を入力
* ひらがな・カタカナOK
* 小文字「ゃゅょっ」は正規化
* 長音「ー」は前の母音に変換 or 無視
* 記号，空白，英数字は除外

### タイマー

* 初期は30秒
* 正解したら次の問題へ
* 連続正解数をスコアにする
* 難易度で秒数を変える

  * Easy：60秒
  * Normal：30秒
  * Hard：15秒

### 判定

```text
前の曲の読みの最後の文字 === 次の曲の読みの最初の文字
```

例：

```text
よるにかける
↓
るーじゅの伝言
```

なら「る」でOK．

### 検索

* Spotify APIで曲名検索
* 検索結果を10件表示
* 曲名，アーティスト，ジャケット画像を表示
* 選択したら読み仮名入力へ

### 結果画面

* スコア
* 使った曲一覧
* 最高記録
* もう一度遊ぶ
* Spotifyプレイリストとして保存，これは後回しでOK
